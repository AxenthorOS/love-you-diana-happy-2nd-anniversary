# Two Years. Still Us.
A private-in-spirit editorial anniversary microsite for Marcel & Diana.

Built with Astro. No database, analytics, cookies or autoplay. Designed for a mobile share link.

## Develop
npm install
npm run dev
npm run build

## Customize
Edit src/pages/index.astro for text and photos.
Place your own photos in public/photos and reference using the base URL.
This first release intentionally contains no private photos. GitHub Pages is public.

## Deploy
GitHub Actions publishes dist to GitHub Pages on push to main.
